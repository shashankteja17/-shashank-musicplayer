About this player

SHASHANK.MUSICPLAYER is an independent browser audio project inspired by desktop audio enhancers. It does not embed FxSound's desktop engine, and it does not modify Spotify streams. The “Open Spotify” button takes you to Spotify separately.

For a public release, follow the FxSound project's AGPL-3.0 license if you reuse its source code. This starter webpage is a separate browser-based implementation.
